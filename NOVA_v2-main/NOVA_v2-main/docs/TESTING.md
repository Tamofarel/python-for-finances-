## Mocked vs. live

- `ScriptedProvider` in `backend/tests/conftest.py` is a deterministic, **test-only** provider used to test
  NOVA's own logic. It is not registered in the application.
- `test_providers.py` runs the Ollama adapter against `httpx.MockTransport` and the **official Anthropic SDK**
  against a mocked HTTP transport (SSE events, 401/404/429 errors, model listing). This verifies NOVA's request,
  streaming and error-mapping code, **not** that a live service works.
- Frontend tests mock `fetch`. Voice tests use fake speech adapters, a fake WebSocket and a fake microphone: they verify
  NOVA's logic, not a real microphone, speech service or speakers.
- Backend voice tests use **real** PocketSphinx on synthetic speech (Festival HTS voice). They prove the pipeline and
  the detector work on speech audio; they do not measure accuracy for real voices, accents or rooms.
- `browser_e2e.py` drives the real UI and backend in Chromium; the microphone is Chromium's fake device playing a file.
- The smoke test uses no mocks. When no provider is reachable it marks the live AI step as `UNVERIFIED` and
  checks that NOVA reported the real connection error instead of an answer.

## Verifying a live provider yourself

1. Configure Ollama or Anthropic (README → AI providers).
2. `python scripts/smoke_test.py` — step 6 must say `PASS` with the provider name.
3. In the UI: Models → *Connected*; send a message; refresh the page; the reply is still there.
